# Progamação Estatística 

Repositório utilizado para a aula de programação estatística do professor Tiago Ramos, utilizada para a simulação de métodos computacionais estatísticos como distribuições probabilísticas(uniforme, binomial, Poisson, Normal, etc.). Além da simulação de cadeias de markov e Monte Carlo Simulations.

Matéria lecionada em 2026/2 para a turma de Estatística e Ciência de Dados de 2025
